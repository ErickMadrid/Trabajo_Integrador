# Formulario de Registro Profesional

Este proyecto presenta una interfaz de registro desarrollada con HTML5, enfocada en la captura organizada de datos de usuario. He diseñado la estructura priorizando la semántica y la claridad, asegurando que cada campo esté correctamente vinculado y agrupado.

---

## 🚀 Características del Proyecto

El formulario está diseñado para recolectar información clave de manera eficiente:

*   **Gestión de Perfil:** Campos para nombre, apellidos y selección de género.
*   **Seguridad:** Entradas de contraseña con enmascaramiento de caracteres.
*   **Localización Detallada:** Selector de países sudamericanos y una sección agrupada para la dirección domiciliaria.
*   **Validaciones Legales:** Casillas para aceptación de términos y suscripción a boletines informativos.

---

## 🛠️ Especificaciones Técnicas

*   **Estructura Semántica:** Uso de etiquetas `<label>`, `<fieldset>` y `<legend>` para mejorar la accesibilidad.
*   **Interactividad:** Implementación de valores predeterminados (como Argentina y Soltero/a) para agilizar el flujo de carga.
*   **Compatibilidad:** Código limpio compatible con todos los navegadores modernos.

---

## 📂 Uso e Instalación

1.  Copia el archivo `index.html` en tu directorio local.
2.  Asegúrate de contar con el archivo `condiciones.html` para el enlace de términos y condiciones.
3.  Ejecuta el archivo en cualquier navegador para visualizar el resultado.

---

Este código sirve como una base sólida para ser escalada con estilos CSS o lógica de validación mediante JavaScript.
